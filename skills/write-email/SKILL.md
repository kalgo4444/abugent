# Write Email

Produce a short, polite, ready-to-send email. The reader should understand the purpose in the first sentence and have every fact they need, nothing more.

## Language

- Write in the language the user's request is written in.
- If the user asks for a different language, use that one.
- Translate structural parts too (greeting, sign-off). Uzbek example: "Hurmatli [Ism]," / "Hurmat bilan,".

## Structure

Always use this template:

```
Subject: [clear, specific, 6–8 words]

[Greeting], 

[One sentence stating the purpose.]

[Body: 2–4 short sentences with only the necessary facts — dates, numbers, names, deadlines, the specific ask.]

[Closing phrase],
[Sender name]
[Links, only if relevant]
```

Details:
- **Subject**: 6–8 words, specific enough to find in an inbox later ("Request to reschedule Friday design review" — not "Meeting").
- **Greeting**: "Hello [Name]," in English, "Hurmatli [Ism]," in Uzbek, or the natural formal equivalent in other languages.
- **First sentence**: the purpose. No warm-up like "I hope this email finds you well" — it delays the point.
- **Body**: 2–4 short sentences. Include only facts the reader needs to act or understand. If there is a request, state it clearly with a deadline when relevant.
- **Sign-off**: short closing phrase + sender name. Add links (portfolio, document, calendar) only when they serve the purpose.

## Length

The full email (excluding subject) stays within 100–150 words. If the content doesn't fit, cut background and keep the ask and key facts.

## Tone

Direct and courteous. No flattery, filler, or excessive apologies ("I'm so sorry to bother you", "I really appreciate your amazing work"). One polite phrase is enough.

## Missing information

If the name, sender, dates, or other facts are missing, don't stop to ask — use clear placeholders like `[Name]`, `[Your name]`, `[date]` so the user can fill them in quickly. Ask only if the purpose of the email itself is unclear.

## Output

Return only the email text, ready to copy and send. No commentary before or after, unless placeholders need a one-line note.

## Example

**Input:** write to my manager Sarah, I need Friday off for a doctor appointment, my tasks are done

**Output:**

```
Subject: Day off request for this Friday

Hello Sarah,

I would like to request a day off this Friday, [date], for a medical appointment.

My current tasks are completed, and the sprint report has been submitted. If anything urgent comes up, I will be reachable by phone in the afternoon. Please let me know if this works for you.

Best regards,
[Your name]
```
