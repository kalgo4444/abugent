# abugent

A small Claude Code plugin with five everyday skills.

| Skill | What it does |
| --- | --- |
| `diagram-maker` | Draws SVG/HTML or Excalidraw diagrams. |
| `geradot` | Reviews important decisions with Herodotus's two-state method. |
| `markitdown` | Converts documents to clean Markdown. |
| `security-audit` | Finds and reports security vulnerabilities in code. |
| `write-email` | Writes short, ready-to-send emails. |

## Install

Requires Claude Code 2.1.275 or later:

```
/plugin install abugent --marketplace kalgo4444/abugent
```

Claude picks the right skill automatically from your request.
